# 决赛（2026-09-20 BO5）盘口复盘 —— 计划 B/C 结果

对手：Aurora Gaming vs Vitality（StarLadder StarSeries Fall 2026 决赛，Vitality 3-1）。
数据源：会话 `manual-1053479-omc2398108`（v2 审计合格，图一 Anubis 按 R3 排除）三路磁带。
脚本：`cs2ml/final_replay.py`。本文件是诊断报告，**不是验收结论**。

## 方法

- **B（盘口为什么变）**：Aurora token 中价序列上每个 |Δ|≥0.03 的跳变，在 ±15s 窗口内找最近的
  5E 事件（击杀/回合结束/回合开始）做标注；平台期 = 相邻跳变间隔。
- **C（fair overlay）**：593 图 v2 重建池的早段（round≤6）比分状态似然比
  LR = P(状态|A赢) / P(状态|A输)，与市场**自己的开盘价**（实力先验）按赔率相乘得到
  adjusted fair；情绪缺口 = 市场 mid − adjusted fair。
  另采样「回合开始窗口」（round_start 事件前最近价，60s 内），剔除局内理性重定价污染。

**结论 1：局内重定价是秒级的**（中位 |延迟| <1s，且常为负——价格先于我们的事件流动，
5E 轮询是分钟级，盘口 WS 是秒级）。想追局内事件吃波段，人类无胜算；这验证了
oracle corr 0.004 的已知结论。
**结论 2：平台期存在**（36-82s 中位）——无大事时价格钉住，大事来时离散跳变。
与用户「情绪一旦形成就不大变，除非大翻盘」的观察一致。

## 关键解读（诚实版）

**不能把这 −0.34 读成白送的钱。** 四张图的图景是：Aurora 输的图缺口深、Aurora 赢的图
缺口为零——这和一个「能读到我们 fair 模型看不见的信息（经济细节/当晚状态/地图理解）的
理性市场」完全兼容。n=4 张图无法区分两种世界：

- 世界 A（情绪世界）：市场对落后方系统性过度折价 → 买缺口是正 EV；
- 世界 B（信息世界）：市场比「比分+赛前价」模型知道更多（尤其经济）→ 缺口是真实信息。

**还没做的判别实验**（下一步）：
1. fair 加入经济分层（round_states 有 ct_equip0/t_equip0；MQTT 快照有实时金钱）——
   把「用户说经济均势」变成受控条件再测缺口；
2. 跨场次样本：每遇到合格采集就积累回合开始缺口样本，看缺口对**次日结果**的校准
   （缺口深 → 落后方真实翻盘率是否系统性高于 fair）；
3. 前向纸面账本：「回合开始缺口 ≤ −0.15 且经济均势 → 买落后方」作为固定规则记账，
   这才是判据。

## 对用户两个具体观察的回答

1. **「3:2 长枪均势没人觉得 55 开」**：量化属实（−0.27~−0.35），但成因未定（情绪 vs 信息）。
2. **「28→18 两条人命」**：在 ±0.03 跳变标注中，击杀是最多的归因类；重定价亚秒级完成。
   这 10 个点 ≈ 我们的局内 fair 估算（(0.45−0.17)×3.5≈10pt），属理性重定价，
   **只有事先持仓的人吃得到**，事后追无意义。
