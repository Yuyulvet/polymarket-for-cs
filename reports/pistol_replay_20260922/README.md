# 手枪局波段策略 —— 磁带 Replay 判决（2026-09-22）

用户策略（cs2-pistol-swing-strategy）：赛前买强队 map winner → 吃手枪局赢后的情绪弹 →
卖出；手枪输则看完第一个长枪局决定去留。脚本 `cs2ml/pistol_replay.py`，产物
`trades.csv` / `summary.json`。

## 方法要点（诚实性设计）

- **样本**：6 个会话里 7 张「从手枪局开始且有深度盘口」的图（半决赛 2 + 决赛 3 +
  9-19 那场 1 + Mirage 由放宽过滤器补回）。1044737/1045844 盘口太稀被弃。
- **选队**：M0=赛前 mid 高者（参考臂）；M1=roster 历史手枪胜率（Beta(3,3) 收缩，
  past-only）；M2=图特异混合。本样本 M0=M1 全同（Vitality 历史 dominance）。
- **时点铁律**：市场领先 5E 轮询 60-120 秒（决赛图 1 完整路径实证：价格 15:03 完成
  手枪重定价，5E 15:04:05 才报 1:0；且**局内就有资金流**——Aurora 优势时其价格
  实时上涨，Vitality 翻盘瞬间砸回）。因此所有成交用**市场时间平台中位数**：
  进场=[t_p1−420, −240]（手枪前稳定 plateau），出场按臂在对应窗口。
- **归因**：手枪赢家用「post-plateau − pre-plateau」价格漂移判定，不用 5E 时点跳变。
  **验证**：决赛 3 图与 5E 逐杀 side 核对 3/3 全中（图 1 决定性证据：mezii/ZywOo/
  ropz 全在 CT 侧、CT 1:0 → Vitality 赢手枪 ✓）。
- **成交**：买入吃 ask、卖出吃 bid（点差如实计入），mid 口径并列。

## 结果（M0 市场选队，n=7）

| 臂 | 含义 | mid 均值 | 含点差均值 | 胜率 |
|---|---|---|---|---|
| A | 手枪结束即抛 | **−1.2pt** | −3.0pt | 4/7 |
| B | 第 3 回合前抛 | −2.4pt | −4.1pt | 4/7 |
| C | 用户完整规则 | −0.4pt | −2.4pt | 3/7 |
| D | 拿到底 | −27pt | −27pt | 0/7 |

**机制量**：
- X（赢时弹幅，A 时点 mid）：+5.5 / +1.5 / +5.0 / **+13.0** → 均值 **+6.25pt**
- Y（输时跌幅，A 时点 mid）：**−14.0** / −8.5 / −11.0 → 均值 **−11.2pt**
- 用全池实测 53.4% 手枪命中率：EV_A = 0.534×6.25 − 0.466×11.2 ≈ **−1.9pt/笔**
- 输腿 C（看完长枪局再退）：−21.5 / −5.5 / −1.0pt——两次救回、一次（Inferno）救不回

## 判决

**策略的核心前提「强队输手枪只下调几个点」在本样本被证伪**：跌幅均值 −11.2pt、
最大 −14pt，而弹幅只有 +6.25pt。不对称是反着的——市场在手枪后对**落后方**的折价
远深于对**领先方**的溢价。叠加 53.4% 的硬币命中率，四个臂全部负期望。

**关键结构性保留**：7 张图全是 0.58-0.65 的重度热门（Vitality），不是用户策略
声明的栖息地（「两队价格相差不大」的均势图）。热门价里弹幅被压制、跌幅被放大
（缺口深度与先验优势正相关，与决赛复盘 C 一致）。**均势价（0.50-0.55）图上的
X/Y 仍未测量**——那是该策略真正该被审判的角落，需要更多均势比赛的秒级磁带。
