# CS2 波段趋势研究协议 v1

状态：2026-09-19 冻结为第一版开发协议。仅用于只读采集和纸面研究，不连接钱包，不生成真实订单。

协议标识为 `cs2_swing_trend_v1`。任何改变预测时点、持仓时间、成交定义或主要评价方式的修改都必须产生新协议版本，不能回写 v1 的历史结果。

## 研究问题

主要问题不是“能否猜中最终地图胜方”，而是：在一个当时可识别的比赛状态变化后，比赛信息能否在同样的盘口样本上，提高对未来可成交价格和净收益的预测。

固定比较三类模型：只看盘口、只看比赛、盘口加比赛。所有模型必须使用相同决策点、相同系列赛时间前向切分和相同执行标签。

## 决策点

v1 只允许三类机制触发：

1. 手枪局结束后的冻结期装备与经济转化；
2. 回合结束后形成的经济断裂或下一局购买力变化；
3. 赛前实力先验与当前市场价格出现明显偏离。

一个机制状态变化最多生成一个决策点。盘口逐笔更新、视频逐帧采样和同一状态的重复轮询不能扩充成独立样本。

## 固定波段标签

固定持仓区间为 15、30、60、120 秒。入场价是比赛状态实际收到以后，加上实测模型耗时和该市场 `secondsDelay` 后，第一份可成交卖盘；退出价是目标时刻之后第一份可成交买盘。净收益等于退出所得减去入场成本和两边实际费用。

禁止使用中间价假装成交，禁止用未来窗口最高价作为退出，禁止使用允许成交时间以前收到的盘口。仓位回放需要完整深度；只有最佳买卖价的数据只能做诊断，不能进入规模化收益验收。

## 时间和身份边界

启动时的历史快照、断线恢复回填和未知时序事件不参与严格回测。必须保存比赛事件收到时间、状态收到时间、模型完成时间、盘口收到时间和允许成交时间。未知的游戏服务器事件时间保持未知，不能由本地收到时间倒推。

每个会话必须明确绑定 5E match、Polymarket event、地图 bout、market、condition 和双方 token。Map 1/2/3 不允许互相回退。采集必须实时看到第一回合和终局回合，三路有效覆盖至少重叠五分钟。

## 开发与验收

开发阶段可以选择模型、特征、阈值和退出规则，但不得把开发结果称为盈利证据。冻结最终候选后，使用新系列赛进行纸面验收。主要报告 Brier、Log loss、价格误差、概率校准、扣费净收益、最大回撤和按系列赛计算的不确定性。

通过历史诊断不自动启用真钱。实盘需要单独授权、执行验证和风险上限。

机器可读协议、会话格式校验和现金流计算位于 `cs2ml.trend_protocol`；采集完整性闸门位于 `cs2ml.live_session_audit`。
