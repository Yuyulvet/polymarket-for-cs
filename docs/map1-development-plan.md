# Map 1 开发与验证约定

记录日期：2026-09-16。用户确认：先完成开发与验证，再讨论尝试实盘。

## 不变的边界

- 当前阶段只运行公开行情读取、人工确认、研究预测和纸面交易。
- 不接钱包，不收集私钥，不创建授权，不发送真实订单，不充值。
- 测试通过代表工程行为符合预期，不代表策略盈利，也不自动解锁实盘。
- 真实交易需要新的明确授权、独立的执行验收和预先确定的风险预算。
- 不修改或覆盖旧研究数据；工作台数据单独存储。

## 第一版范围

只覆盖地图与首发已确认、尚未开打的 Map 1；每场最多一次纸面入场，持有到显式结算。
第一版人工确认 veto 和五人阵容，保存来源、声明发布时间和本地确认时间。
程序不能把赛后信息或人工回填的时间冒充当时已收到的信息。

开发顺序：

1. 自动发现公开 CS2 Map 1 市场，严格校验身份，保留跳过与拒绝原因。
2. 本地确认页面，录入地图、五人 Steam ID 和证据来源；无需钱包。
3. 持续公开盘口采集、可恢复存储、连接失败记录和显式启停。
4. 自动核验明确的官方二元结算；平分、冲突或未知结果保持待核验，不用末价推断。
5. 复盘页面：虚拟现金、持仓成本、已实现盈亏、成交与拒绝记录、独立场次及概率比较。
6. 自动化测试、公开接口只读冒烟测试、页面交互测试。

## 验证门槛

- 身份、时间、盘口、成本和结算检查必须失败关闭；断线或未知结果不得生成虚构成交/收益。
- 重启后保留记录；重复采集、重复结算不能重复记账。
- 原始观测和策略参数保留，纸面账本能够确定性重建。
- 用新发生的独立比赛做前向验证，包括未交易场次；不把行情快照数量当样本量。
- 同时比较市场、模型及过去数据拟合的组合；概率指标不能代替扣费收益。
- 事先固定策略，评估成本压力、回撤和统计不确定性；场数达标不等于证明盈利。
- 当前离线留出集 60 场，模型 Brier 0.2577，50% 基线 0.25；没有实盘盈利证据。
