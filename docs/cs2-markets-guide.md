# Polymarket CS2 盘口百科（实盘调研）

> 调研日期：2026-08-23，全部来自 gamma-api / clob / data-api 生产接口实测（含 EWC 2026 总决赛开赛前后实时采样）。
> 本文回答：CS2 有什么盘、怎么下、怎么结算、流动性够不够。

---

## 一、两套市场体系（先分清楚）

| | **比赛盘（match markets）** | **冠军盘/花絮盘（futures & props）** |
|---|---|---|
| 标签 | `counter-strike-2`（tag_id=100780）/ `esports` | `cs2`（tag_id=100677） |
| 形式 | 一场比赛一个事件，内含 20 个左右子盘 | 锦标赛冠军（negRisk 多队）+ 各类长线话题盘 |
| 基础设施 | **官方体育体系**（与 NBA/足球同套：PandaScore 数据管线、moneyline/handicap/totals 全套、滚球支持、专用结算 adapter） | 传统预测市场（negRisk，UMA 标准流程） |
| 流动性 | 单场 $1M-$10M（Tier-1），价差 1 分 | 分散薄簿：热门队价差 3-4 分、5 分内深度仅几百刀 |
| 当前规模 | 92 场比赛盘 / 1310 个活跃子盘 | EWC 冠军盘 $3.9M 分散在 38 个子市场 |

## 二、比赛盘的完整家族（一场 BO3 = 20 个盘，实测 HOTU vs CYBERSHOKE）

```
事件: Counter-Strike: A vs B (BO3) - 赛事名  [gameStartTime, secondsDelay=1]
├─ moneyline          系列赛胜者（主盘，深度最好）
├─ child_moneyline    Map 1/2/3 Winner（每图胜者盘）
├─ map_handicap       地图让分（-1.5，两个方向各一本）
├─ totals             Games Total: O/U 2.5（是否打满三图）
├─ round_handicap_game_N   每图回合让分（-3.5/-6.5/-9.5 多条线）
├─ round_over_under_game_N 每图回合总数 O/U（21.5/24.5 多条线）
└─ cs2_odd_even_total_kills/rounds  每图击杀/回合数奇偶（纯赌大小，~55% 的盘都是这类）
```

历史量级参考：IEM Cologne Major 2026 冠军盘 $25.7M；Spirit vs G2 BO3 单场 $10.3M；FURIA vs FUT BO3 $9.9M。

## 三、各盘型结算规则（实测原文要点）

所有比赛盘结算源统一为 **https://hltv.org**；HLTV 2 小时内未发布结果则采用可信报道共识。

| 盘型 | 结算要点 | 特殊规则 |
|---|---|---|
| moneyline | 系列赛胜者 | 取消/平局/延期超 7 天 → **50-50**；赛中弃权 → 判获胜方；赛前 walkover → 50-50 |
| Map Winner | 该图胜者 | 该图未打完 → 50-50；系列赛已定胜负而该图未打 → 50-50 |
| Map Handicap (-1.5) | 赢 2 张图以上 | 弃权获得的图计入让分；赛中被弃 → 50-50 |
| Games Total O/U 2.5 | 是否打满 3 图 | 弃权图计入总局数 |
| Round O/U（每图） | 该图双方总回合数 | 与谁赢无关；图未打完 → 50-50；以实际回合数结算 |
| Round Handicap（每图） | 该图回合分差 | 同上，独立于胜负 |
| Odd/Even | 总击杀/总回合数奇偶 | **不含队友伤害/自杀**；图未打 → 50-50 |
| 队名容错 | — | 缩写/赞助商前后缀/学院队名均视为同一队；无法唯一识别才 50-50 |

**对策略最关键的规则**：大量"异常结束"路径（取消、延期 7 天+、赛前弃权、图未打完）都结算 50-50。这意味着：买便宜方（如 $0.15）博爆冷时，**弃权风险不是归零而是回本价**--尾部风险比想象中温和；反之买贵方时弃权会亏掉时间价值。另外 50-50 结算 = 按 $0.50 赎回。

## 四、实盘交易参数（实测）

- **min_order_size = 5 股**（全 CS2 统一）
- **tick_size 动态**：价格在 ~[0.07, 0.93] 区间 0.01，区间外 0.001（有粘性，涨价后可能仍保留 0.001）
- **费用**：`sports_fees_v3`，taker = 0.05 × 股数 × p × (1−p)（中价 ≈ 名义 2.5%）；**maker 零费 + 15% 返佣 + LP 奖励**（≥50 股、价差 4.5 分内挂单）
- **secondsDelay = 1**（滚球时仅 1 秒撮合延迟，可忽略）
- **clearBookOnStart = True**：开赛瞬间清空全部挂单（实测：总决赛簿深 $380K → $25K，10 分钟重建到 ~$30K）
- **neg_risk**：比赛盘 False（独立二元，两本簿互为镜像：买 A = 卖 B）；冠军盘 True
- 市场创建：赛前 15-25 小时；**结算：赛后 ~16 分钟**提交（customLiveness=900s 争议窗，umaBond=$250）
- 结算后订单簿整体删除

## 五、流动性/容量实测表（$50-500 单笔仓位视角）

| 盘型 | $50 | $500 | 实测深度 |
|---|---|---|---|
| Tier-1 moneyline（EWC/Major/BLAST 季后赛） | ✅ 轻松 | ✅ 轻松 | 顶档 $50-80K，价差 1 分；滚球中仍有 $10-30K |
| Tier-1 Map Winner（1-3 图） | ✅ | ✅ | 5 分深度 $6K-40K，但**单侧可能极薄**（实测 $41K vs $202） |
| Tier-2/3 moneyline（CCT/EPL/ESEA） | ✅ | ⚠️ 勉强 | 顶档 $200-2K，$500 吃单多付 1-2 分 |
| Map handicap / Games Total | ✅ | ✅ | $3K-120K 不等 |
| Round 级衍生盘（让分/O/U） | ⚠️ 最小单 | ❌ | 深度 <$100，基本无流动性 |
| Odd/Even | ❌ | ❌ | 赌博盘，且无信息优势可言 |
| 冠军盘（热门队） | ⚠️ | ⚠️ | 价差 3-4 分 + 5 分内 $400-900，隐性成本 1.5-2% |
| 花絮盘（MVP/转会/Valve 更新） | ⚠️ | ❌ | 几十到几百刀 |

## 六、滚球（live）实测行为

- **滚球交易真实存在且活跃**：总决赛开赛 15 分钟成交 $177K/166 笔
- 波动剧烈：FURIA vs FUT 一场 BO3，30 分钟内 0.845 → 0.125（72 分振幅）
- 冠军盘价格是**阶梯式跳变**（比赛解决的整点附近 ±8~19 分），不是连续漂移
- 事件对象带实时比分字段：`score="000-000|0-0|Bo5"`、`period="0/5"`、PandaScore matchId（**官方数据管线是 PandaScore**，我们自己的实时数据可以和它赛跑）
- 卫生问题：tier-3 比赛赛后数天仍有半结算状态（主盘已结算、Map 盘还挂着）--扫描器要过滤

## 七、冠军盘/花絮盘宇宙（cs2 tag，活跃实例）

- **冠军盘**：EWC 2026 Winner（$3.9M/38 队）、BLAST Porto Winner 等
- **赛事花絮**：MVP（113 个子市场）、夺冠队伍所在小组、总刀杀数、是否有 13-0、1.30+ Rating 选手
- **转会盘**：Vitality/NAVI/Astralis/Spirit 等"9 月前是否换阵"（$3K-10K 量级）
- **Valve/游戏盘**：地图池变动（Cobblestone 入池？）、贴纸交易、Shootout OT
- **梗盘**：ropz 再被拦车？ArrowCS 直播吃虫？
- 历史：单次赛事冠军盘最高 $25.7M（IEM Cologne Major 2026）；"PGL 总决赛会说什么"梗盘 $5.7M

注意冠军盘的 negRisk 是 augmented 版本：实测含 A/B/C/D/E **占位市场** + "another team" 兜底--只交易命名队伍，不碰 Other。

## 八、对策略的修订结论

1. **主战场确认：比赛盘 moneyline + Map Winner**（赛前 + 滚球），流动性/波动/信息优势三者俱备
2. **滚球从"第三阶段候选"升格为核心方向**：secondsDelay=1 几乎无摩擦、深度足够、分钟级 10-70 分波动、官方比分数据（PandaScore）可以被我们的回合级模型击败
3. **Map Winner 盘是回合级模型的直接变现口**：你的"某回合胜利后下一回合会怎样"模型直接定价每图胜率
4. Round 让分/O/U 盘虽然深度目前死透，但**规则上完全可由回合级模型定价**--值得做只挂 maker 单的低频试验（零费 + LP 奖励，等流动性找上门）
5. Odd/Even 和无深度的盘直接进黑名单
6. 冠军盘只做套利监控（negRisk 组内 Σ 检查），不做执行
7. 转会/Valve 花絮盘：你的领域知识独占区，但流动性限制只能小仓玩
8. 50-50 结算规则改变尾部风险计算：爆冷买方的弃权风险是回本而非归零

## 九、技术注意事项（实测坑）

- CLOB API 对默认 python UA 返回 403，必须带浏览器 User-Agent
- `clobTokenIds` 是**双重 JSON 编码**字符串，需两次 parse
- Gamma 的 `liquidity` 字段含远端档位虚高，评估深度必须看 `/book` 实际簿
- CLOB 价格历史对老市场有保留期（6 月的查不到 1m 精度；昨天的可以）
- 比赛盘两本簿互为镜像，吃深度要两边一起看
